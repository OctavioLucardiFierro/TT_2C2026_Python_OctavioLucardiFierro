Repositorio para la entrega final del curso de Talento Tech, curso intro a Python.

## Proyecto final: Sistema de gestión de inventario

Programa de terminal hecho en Python que permite administrar los productos de un
inventario (en este caso, una tienda de videojuegos y mangas). Los datos se guardan
en una base de datos SQLite llamada `inventario.db`, así que no se pierden al cerrar
el programa (a diferencia de la Pre-Entrega, que guardaba los productos en una lista
en memoria).
